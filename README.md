1) Crie um sistema WEB que permita cadastrar mercadorias e apresentar a
quantidade de cada mercadoria no estoque da empesa

• O sistema deve manter mercadorias (criar, listar, editar e excluir )
• O sistema deve manter fornecedores (criar, listar, editar e excluir )

Deve haver

1. uma tela para adição da mercadoria,
2. uma tela para edição da mercadoria,
3. uma tela para listagem de todas as mercadorias da empresa, que deve
mostrar os botões de ação e a quantidade de cada mercadoria que está em
estoque atualmente
4. uma tela para adição de fornecedores,
5. uma tela para edição de fornecedores,
6. uma tela para listagem de todos os fornecedores da empresa,
7. uma tela que mostre todas as mercadorias de um determinado fornecedor
   
• Quando uma mercadoria for deletada o sistema deve recalcular a quantidade de
unidades dessa mercadoria e apresentar em tela a nova quantidade da mercadoria
no estoque.

• Quando a quantidade do estoque for igual a 0 a mercadoria não deve ser
apresentada na lista de mercadorias da empresa.

• O sistema deve ter uma tela adicional que possibilite que o usuário faça o login
para o sistema para ter acesso as telas

OBS. 1: Dados das mercadorias que devem constar no sistema: Nome, descrição,
data de validade, data de cadastro no sistema, fornecedor, contato do fornecedor
endereço do fornecedor, quantidade.

OBS. 2:O sistema deve estar implementado seguindo o padrão de orientação a
Objetos e MVC (Model View Controller) tanto no backend como no frontend.

OBS. 3:Preferencialmente configurar para utilizar JAVA na versão 21

OBS. 4: Se não rodar perde ponto

OBS. 5: Constatada cópia de trabalho a nota final do trabalho será dividida
igualmente pela quantidade de grupos que realizaram a cópia. Exemplo: 3 grupos
copiaram a base e apenas alteraram as labels da interface e tiraram 90, o cálculo
será 90/3 = 30 para cada integrante dos grupos.

OBS. 6: No projeto, deve constar o nome dos integrantes do grupo
Grupos – Máximo de 4 integrantes

OBS. 8: O Projeto, deve ser apresentado, obrigatoriamente, se não for apresentado,
apenas entregue valerá 10 pontos na nota bimestral
Arquivos a serem entregues: Pasta do projeto um arquivo com o link que
permita o download do zip da Pasta do projeto
Apenas um integrante de cada grupo deve entregar o projeto no MOODLE
